# YourMajor 🎓

YourMajor is a Machine Learning project designed to predict a student's major category based on relevant student data.

The project aims to explore how machine learning can be used to help identify potential academic major categories and provide data-driven insights with KNN algorithm machine learning.

## About The Project

Choosing a suitable major can be challenging for students. YourMajor uses machine learning to analyze student-related information and predict the most suitable major category.

The project covers the complete machine learning workflow:

- Data preprocessing
- Exploratory Data Analysis (EDA)
- Feature Engineering
- Model Training
- Model Evaluation
- Prediction and recommendation

## Machine Learning

YourMajor uses a classification approach to predict major categories and Knn algorithm machine learning to give the recommendation based on the 100 nearest characteristic feature score.

The target categories include:

- Business
- Health
- Education
- technique
- social
- technology
- science

Several preprocessing techniques and machine learning methods are applied to prepare the data and build the prediction model.
